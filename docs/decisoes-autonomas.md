# Decisões do orquestrador

Nenhuma destas decisões muda o alvo. Todas podem ser desfeitas pelo checkpoint.

- A faixa 20–45 LPI já estava autorizada. O controle não oferece 15 nem 55.
- O .dtx gravado aqui é um formato próprio. O original não foi publicado.
- As cores da janela se aproximam da miniatura. O hexadecimal exato não foi medido.
- O ângulo é um número de 0 a 90 porque a lista do menu original não apareceu. O valor visível é o processado.
- Só o 30 LPI ganhou o nome Standard, visto na miniatura. Os outros entram só com o número.
- O preset Color não inventa uma cor de camiseta.
- O preset White usa branco puro. Isso vem do nome do preset e do FAQ, não de um hexadecimal publicado.
- Export PNG espera Apply Seps, como na miniatura.
- Gang sheet, AI upscaler, defringe com controle próprio e o .dtx original ficam pendentes.
- O monitor não lê o chat. A frase de parada vira o arquivo `monitor/STOP`.
- O Cursor é detectado pelo `tasklist`. Se o processo some, o monitor fecha.
- O aviso não é modal, para não cobrir o editor. Ele abre na frente e pode ser movido. O primeiro aparece ao iniciar; os seguintes, a cada 15 minutos.
- A restauração principal é a pasta `checkpoints/`. O Git só entra se o repositório já aceitar o commit sem mudar a identidade.
